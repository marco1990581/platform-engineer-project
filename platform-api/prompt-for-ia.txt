Estamos continuando el desarrollo de mi proyecto "Platform API", un proyecto personal para practicar ingeniería de plataformas y backend en Go.

## Objetivo general

Construir una API para administración Linux siguiendo buenas prácticas de arquitectura, código limpio y Git, evitando soluciones rápidas.

La idea es que el proyecto pueda evolucionar en el futuro hacia:

- API REST
- autenticación
- auditoría
- RBAC
- Docker
- Kubernetes
- Prometheus
- Grafana
- Keycloak
- PostgreSQL
- etc.

Quiero que avancemos paso a paso como si estuviéramos desarrollando un producto real.

No quiero grandes saltos.

Siempre:

- un objetivo
- implementación
- pruebas
- git
- documentación

## Problema actual

El login HTML ya existe.

El navegador envía correctamente:

Authorization: Basic ...

Lo confirmé desde Firefox.

Sin embargo:

curl -u marcos:cornucopia http://localhost:8081/filesystem

devuelve

401 Unauthorized

authentication failed

Por lo tanto el problema YA NO está en:

- JavaScript
- router
- middleware
- QEMU
- networking

Todo apunta al backend de autenticación.

Ya revisamos:

basic.go

file_repository.go

y GetByUsername()

La siguiente tarea es depurar el backend agregando logs para descubrir si falla:

- lectura del users.json
- búsqueda del usuario
- comparación bcrypt

No quiero cambiar el diseño todavía.

Primero quiero encontrar exactamente dónde falla.
